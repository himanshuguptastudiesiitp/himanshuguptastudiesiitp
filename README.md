## Asset notes

- All five SVGs are self-contained. Portrait PNGs and WOFF2 font data are embedded inline; SVGs make no external asset requests.
- Animations use CSS and SMIL only. The files include reduced-motion handling and readable non-animated base states.
- Most brand glyphs use Simple Icons and are converted to inline SVG paths. The LinkedIn glyph is a Font Awesome Brands fallback; its CC BY 4.0 attribution is recorded separately. See `assets/ICON-SOURCES.md` and the license files before reuse.
- Display type: Inter Display. Mono type: IBM Plex Mono. Their license notices are in `assets/licenses/`.
- Open `preview.html` locally to view the full profile sequence. The SVG files are intended to stay in the relative `assets/` directory.
